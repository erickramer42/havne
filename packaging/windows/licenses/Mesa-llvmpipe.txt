Mesa llvmpipe in this package (opengl32sw.dll)
==============================================

opengl32sw.dll is the software OpenGL renderer that Qt's Windows
deployment places beside the application. It is the copy in Qt 6.12.0's
Windows kit, unmodified, signed by The Qt Company.

What is established:

- Qt's documentation lists this file as Mesa llvmpipe, under the MIT
  License and the Boost Software License 1.0, and gives the Khronos and
  C11 threads notices below:
  https://doc.qt.io/qt-6/qt-attribution-llvmpipe.html
- The Mesa notice below is Mesa's own, from docs/license.html at its tag
  mesa-11.2.2. Qt's page gives the same notice but names Brian Paul in
  the disclaimer, where Mesa's reads "the authors or copyright holders".
- The file's own text strings name Mesa 11.2.2 and LLVM 3.6.2.

What is not established:

- Qt publishes no software bill of materials or build record for this
  file, so its exact sources, its build options and everything it links
  can't be confirmed from what is published.
- Qt's page doesn't mention LLVM. LLVM's license is here because the
  file's strings name it, and its release is only what they say.

The Boost Software License's text is Boost's own,
https://www.boost.org/LICENSE_1_0.txt, and LLVM's is LICENSE.TXT at
https://github.com/llvm/llvm-project/tree/llvmorg-3.6.2/llvm.
